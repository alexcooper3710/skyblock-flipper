# market-data

Generated by `.github/workflows/market.yml`. Do not edit or commit here by hand -
this branch is an orphan and is force-replaced on every run.

- `meta.json`   - when it ran, how long it took, what it found
- `bazaar.json` - top of book for every bazaar product, plus order and craft flips
- `ah.json`     - the flip board, the lowest-BIN wall, and sold medians
- `sold-raw.json` - the rolling sold window, read back by the next run

Consumed by the page at `docs/` over raw.githubusercontent.com.
